Administrador

1. Inicio

  1. Entra a Inicio para revisar estadisticas actuales, actividad reciente y un resumen rapido del dia.
  2. Usa esta pantalla como tablero principal para detectar vehiculos pendientes, pagos por cobrar y movimiento reciente.

2. Nueva entrada

  1. Captura la ficha fisica, el nombre del cliente, tipo de vehiculo y placas o identificador.
  2. En Modalidad elige si sera Por hora o Por semana.
  3. Si es Por hora, el sistema llevara el tiempo en cuenta continua.
  4. Si es Por semana, la vigencia de 6 dias empieza al registrar la entrada del vehiculo.
  5. Si el cliente pide extras, pulsa Agregar servicios y selecciona lavado, cambio de aceite y precio del aceite cuando aplique.
  6. Guarda la entrada para generar el ticket y dejar el registro activo en el estacionamiento.

3. Registros

  1. En Registros puedes buscar por ficha, cliente, placas o tipo de vehiculo.
  2. Usa Editar para abrir la ventana del registro y corregir datos, servicios, modalidad, notas y estado.
  3. Usa Registrar salida para cerrar una estancia por hora.
  4. Usa Marcar pagado cuando el cliente liquide, incluso si el pago se realiza despues de la salida.
  5. Para registros semanales puedes usar Marcar salida semanal para llevar control parcial de salidas sin cerrar la semana.
  6. Desde la misma ventana puedes reimprimir el ticket o, si es necesario, eliminar un registro.

4. Tarifas

  1. En Tarifas defines los tipos de vehiculo disponibles.
  2. Actualiza el precio, esquema de cobro y promociones u ofertas especiales.
  3. Si agregas un nuevo tipo de vehiculo aqui, despues aparecera en el formulario de nueva entrada.

5. Empleados

  1. En Empleados puedes crear nuevos accesos para el personal.
  2. Tambien puedes editar nombre, usuario, contrasena y estado activo de cada empleado.
  3. Si un usuario ya no debe entrar, puedes desactivarlo o eliminarlo segun corresponda.

6. Tickets y documentos

  1. Despues de cada entrada se genera un ticket con la ficha fisica, datos del vehiculo y servicios aplicados.
  2. Puedes abrir el ticket en PDF, descargarlo o imprimirlo desde el mismo registro.

7. Cortes y control

  1. Usa los cortes para revisar ingresos, pendientes y vehiculos atendidos en un periodo.
  2. Esto te ayuda a cerrar turnos y validar el dinero cobrado frente a los registros pagados.

Empleado

1. Inicio

  1. Al entrar veras un resumen con informacion actual del estacionamiento.
  2. Usa esta vista para ubicar rapido si hay movimientos pendientes o registros recientes.

2. Nueva entrada

  1. Entra a Nueva entrada para registrar un vehiculo nuevo.
  2. Captura ficha, cliente, tipo de vehiculo, modalidad y placas.
  3. Si el cliente pide extras, pulsa Agregar servicios y marca los servicios solicitados.
  4. Si seleccionas Cambio de aceite, captura tambien el precio del aceite para que se cobre correctamente.
  5. Guarda la entrada y entrega el ticket generado al cliente.

3. Registros

  1. Usa el buscador para localizar un registro por ficha, cliente, placas o tipo de vehiculo.
  2. Pulsa Editar para corregir datos del registro si hubo un error al capturarlo.
  3. Pulsa Registrar salida cuando el vehiculo se retire y el sistema calcule el cobro.
  4. Si el cliente paga despues, usa Marcar pagado por separado.
  5. En estancias por semana puedes usar Marcar salida semanal para registrar salidas parciales.

4. Ticket

  1. Desde el registro puedes volver a abrir el ticket PDF cuando el cliente lo necesite.
  2. El ticket sirve para imprimir, descargar o volver a revisar la informacion capturada.

5. Limites del empleado

  1. El empleado puede registrar entradas, salidas, pagos y correcciones basicas del registro.
  2. La administracion de tarifas, usuarios y eliminacion de registros queda reservada al administrador.

Anticipos semanales

Sirven para cobrar la tarifa semanal cuando el cliente quiere pagar hoy y traer su vehiculo otro dia.

  1. Al recibir el dinero: abre Nueva entrada, ve a Adelantos semanales y elige Registrar adelanto pendiente de entrada.
  2. Escribe el nombre del cliente y la placa o identificador. Selecciona el tipo de vehiculo, revisa el importe y pulsa Registrar pago recibido. El ingreso queda en el corte de ese dia, a nombre de quien lo cobro.
  3. Cuando llegue el vehiculo: busca al cliente o la placa en Pendientes de entrada, captura el numero de ficha fisica y pulsa Activar al llegar.
  4. La ficha se abre como pagada. Los seis dias empiezan en ese momento y puedes consultar la vigencia en la vista del ticket.

Ejemplo. Si el cliente paga el sabado y trae la moto el lunes, el dinero entra en el corte del sabado. El lunes solo asignas la ficha y activas la semana.

Preguntas frecuentes

La ficha fisica ya se uso antes. Puedo volver a usarla?

Si. La ficha es reutilizable. Solo se bloquea si esa misma ficha sigue asignada a un vehiculo que aun no tiene salida.

Quien puede registrar salidas?

Tanto administradores como empleados pueden registrar la salida de un vehiculo desde la pantalla de registros.

Quien puede marcar pagos o eliminar registros? {% if current_user.has_admin_access %}

Como administrador puedes marcar pagos, editar, registrar salidas y eliminar registros desde la vista de registros.

{% else %}

Como empleado puedes marcar pagos y registrar salidas desde registros, pero la eliminacion queda reservada al administrador.

{% endif %}
Como funciona la modalidad por semana?

La semana cuenta 6 dias pagados. En pantalla veras cuantos dias restantes quedan de esa semana y podras registrar salidas semanales parciales cuando el cliente entre y salga durante esos dias.

Como funcionan los servicios extra?

El lavado de moto suma $20. El cambio de aceite suma $40 mas el precio del aceite que captures al registrar la entrada o al editarla. Todo eso se agrega automaticamente al cobro final.

Que hago si no encuentro un registro?

Busca por ficha fisica, nombre del cliente, placas o tipo de vehiculo dentro de la seccion de registros.

Cuando debo usar Editar y cuando Registrar salida?

Usa Editar cuando necesites corregir datos del registro. Usa Registrar salida cuando el vehiculo realmente abandona el estacionamiento y quieres calcular el cobro.

Que pasa si el cliente paga despues?

Puedes registrar primero la salida y dejar el registro pendiente. Cuando el cliente pague, marca el registro como pagado desde la misma pantalla.
